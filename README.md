# Resoluções de Desafios — Bootcamp Java DIO + Accenture

Este repositório reúne minhas resoluções dos desafios, exercícios e projetos realizados durante o Bootcamp Java da DIO em parceria com a Accenture.
O objetivo é registrar minha evolução, organizar o estudo e compartilhar soluções claras e bem estruturadas em Java.

## 📚 Conteúdo

- Exercícios de Sintaxe Java

- Programação Orientada a Objetos (POO)

- Collections e Streams

- Maven e Gradle

- Debugging

- Tratamento de Exceções

- Boas Práticas

- API REST com Spring Boot 

- Design Patterns

- Utilização de Docker

- Nuvem com AWS

- Desafios práticos diversos

### Cada pasta contém:

- Código-fonte organizado

- Descrição do desafio

- Minha solução

- (Opcional) Alternativas, melhorias e anotações

- Java 21+

- Maven ou Gradle

- JDK OpenJDK

- JUnit 5 (para testes, se usado)

- Git & GitHub

## 📎 Como Executar

1. Clone o repositório:

```
git clone https://github.com/SEU-USUARIO/nome-do-repo.git
```

2. Entre na pasta do exercício desejado:

```
cd bootcamp-java-dio-accenture
```

3. Compile e execute:

- Para desafios simples:

```
cd src
javac Main.java
```

- Para desafios complexos:

```
mvn clean install
mvn spring-boot:run
```
